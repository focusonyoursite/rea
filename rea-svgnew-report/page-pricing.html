Limits, billing and the API.

How many vectorizations do I get?
Free includes 3 vectorizations per day. Pro includes 1,000 vectorizations per month for $9.99. Pro accounts can top up with extra credits at 2¢ each from the account page. You can also try one conversion without an account.
What counts as a vectorization?
Each image you convert to SVG counts as one, whether you use the site, the API or the MCP server. Failed conversions don't count, and editing or re-downloading a result in the editor is free. Background removal through the API also counts as one.
Can I use the SVGs commercially?
On Pro, yes: websites, products, client work and print. The Free plan is for personal use.
How do I cancel?
Any time, from your account page. Pro stays active until the end of the period you've paid for and then moves to Free. You can resume before then. Go to account
Is there an API?
Yes. Pro includes the REST API and an MCP server for AI agents, using the same monthly allowance. Create an API key on your account page. Read the API docs
How is payment handled?
Payments go through Stripe. We never see or store your card details.
