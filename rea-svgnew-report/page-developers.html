Quick start

Vectorize an image in one curl command.

1Get an API key from your Account page
2
export SVG_NEW_API_KEY="svk_your_key_here"
3
curl -X POST https://svg.new/api/agent/vectorize \
  -H "Authorization: Bearer $SVG_NEW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,'$(base64 -i input.png)'"}'

MCP Server

Connect SVG.new to any MCP-compatible client — Claude, Claude Code, Cursor, Windsurf, and more. AI agents can discover and use vectorization tools automatically.

Hosted MCP endpoint

Connect to https://svg.new/api/mcp using Streamable HTTP. It accepts either of two credentials. Clients that support OAuth sign in with an SVG.new account: they discover it from https://svg.new/.well-known/oauth-protected-resource and register with dynamic client registration. Claude and Claude Code work this way; see the MCP server guide.

Or send an API key in the Authorization: Bearer svk_... header on every request:

{
  "mcpServers": {
    "svg-new": {
      "type": "http",
      "url": "https://svg.new/api/mcp",
      "headers": {
        "Authorization": "Bearer svk_your_key_here"
      }
    }
  }
}

Local MCP server

{
  "mcpServers": {
    "svg-new": {
      "command": "npx",
      "args": ["@svgnew/mcp"],
      "env": {
        "SVG_NEW_API_KEY": "svk_your_key_here"
      }
    }
  }
}

Claude Code

Plugin

Full plugin with skills, MCP integration, and auto-updates. Install from the marketplace.

/plugin marketplace add svgnew/plugin
/plugin install svg-vectorizer@svg-new-tools

Then run /mcp, pick the plugin's svg-new server and choose Authenticate to sign in with your SVG.new account. No API key needed.

Included skills

/svg-vectorizer:vectorize logo.pngConvert image to SVG
/svg-vectorizer:recolor icon.svgChange colors
/svg-vectorizer:simplify icon.svgReduce palette
/svg-vectorizer:remove-background art.svgRemove background
/svg-vectorizer:batch ./images/Batch process folder

Or just ask naturally — “vectorize this logo”, “convert all PNGs to SVG”, “change the red to blue”.

One-liner

Quick Skill Install

Don't need the full plugin? Add the /svg skill to Claude Code with one command.

mkdir -p ~/.claude/skills/svg-new && curl -s https://svg.new/skill.md -o ~/.claude/skills/svg-new/SKILL.md

Then use /svg in Claude Code or just say “vectorize this image”.
